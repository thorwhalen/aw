aw.base¶

Core protocols and base classes for agentic workflows.

This module provides the foundational abstractions for building AI agents that follow the AgenticStep protocol with ReAct pattern (Reason-Act-Observe).

class aw.base.AgenticStep[ArtifactType](*args, **kwargs)[source]¶

Bases: Protocol[ArtifactType]

Protocol defining the interface for any agentic step in a workflow.

Each step follows the ReAct pattern:

  1. Reason (Thought): Analyze input and context

  2. Act (Action): Generate and execute code or use tools

  3. Observe: Capture results and validate

  4. Repeat or finish based on validation

Example

>>> class MyAgent:
...     def execute(self, input_data, context):
...         # Agent implementation
...         return result, metadata

class aw.base.Tool(*args, **kwargs)[source]¶

Bases: Protocol

Protocol for tools that agents can use.

Tools are callable objects that perform specific actions like executing code, sampling files, or calling external APIs.

Example

>>> class FileSampler:
...     def __call__(self, uri):
...         # Sample file logic
...         return {'extension': '.csv', 'sample': '...'}
class aw.base.Validator(*args, **kwargs)[source]¶

Bases: Protocol

Protocol for validation functions.

Validators check if an artifact meets requirements and return both a success indicator and detailed information.

Example

>>> def is_non_empty_dataframe(df):
...     success = df is not None and len(df) > 0
...     info = {'shape': df.shape if success else None}
...     return success, info
